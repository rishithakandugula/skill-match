# SkillMatch - Skill Management & Career Recommendation System

SkillMatch is a web-based Skill Management and Career Recommendation System designed to help students manage their technical skills, identify skill gaps, improve their abilities, and discover suitable courses, projects, internships, and jobs.

The system creates a student skill profile and uses the student's skills, proficiency levels, career goals, and progress to provide personalized career recommendations.


---

## 📌 Project Overview

Students often have difficulty identifying which skills they need to develop for their desired career.

SkillMatch solves this problem by providing a single platform where students can:

- Create an account
- Build a personal profile
- Add and manage skills
- Track skill proficiency
- Take skill assessments
- Identify skill gaps
- Find recommended courses
- Find suitable projects
- Discover internships
- Discover job opportunities
- Track learning progress
- Check career readiness
- Receive personalized recommendations


---

## 🎯 Objectives

The main objectives of SkillMatch are:

1. Help students manage their skills.
2. Measure and track skill proficiency.
3. Identify missing skills for a target career.
4. Recommend suitable learning resources.
5. Recommend practical projects.
6. Match students with internships and jobs.
7. Track student learning progress.
8. Improve career readiness.
9. Provide a personalized career roadmap.

## 🚀 Main Features

### 1. User Registration

Students can create an account by providing:

- Full Name
- Email
- College
- Branch
- Study Year
- Career Goal
- Password

---

### 2. User Login

Registered users can securely log in to their account.

The login system verifies:

- Email
- Password

After successful login, the user is redirected to the dashboard.


---

### 3. Student Profile

Students can maintain their personal and professional information.

Profile information includes:

- Name
- Email
- Phone
- Location
- College
- Degree
- Branch
- Study Year
- Graduation Year
- Career Goal
- Preferred Role
- Preferred Location
- Career Level
- Work Type
- GitHub
- LinkedIn
- Portfolio
- Resume


---

### 4. Skill Management

Students can add and manage their skills.

Example:

| Skill | Category | Level | Score |
|------|----------|-------|-------|
| HTML | Web Development | Advanced | 90% |
| CSS | Web Development | Advanced | 85% |
| JavaScript | Programming | Intermediate | 65% |
| Python | Programming | Intermediate | 60% |
| SQL | Database | Intermediate | 70% |
| React | Web Development | Beginner | 40% |

Students can:

- Add skills
- Search skills
- Edit skill scores
- Delete skills
- View skill details
- Track skill progress
